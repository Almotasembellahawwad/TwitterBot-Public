## ✨ Features

- 🚀 **Automated Tweeting:** Schedule and post tweets with customizable content seamlessly.
- 🎯 **Human-like Patterns:** Smart scheduling with randomized delays to avoid detection.
- ⚡ **Lightning-Fast:** Optimized performance with precise wait times.
- 🤝 **Automated Interactions:** Handles likes and retweets based on specific parameters.
- 🎭 **Headless Mode:** Can run entirely in the background without opening a visible browser window.
- 🛡️ **Advanced Recovery:** Robust error handling and auto-recovery from connection drops.
- ✅ **Verification System:** Built-in tweet verification to ensure successful posting.

- **Python 3.8+** installed
- **Google Chrome** browser installed
- Matching **ChromeDriver** (managed automatically by webdriver-manager if configured)

## 🔧 Installation & Quick Start

**1. Clone the repository:**
```bash
git clone https://github.com/mohasbks/TwitterBot-Public.git
cd TwitterBot-Public
```

**2. Install required dependencies:**
```bash
pip install -r requirements.txt
```

**3. Configure your credentials:**
*(Make sure to add your Twitter credentials securely in the required configuration file before running).*

**4. Run the Bot:**
You can start the bot using the included batch file for Windows:
```cmd
run_bot.bat
```
Or directly via Python:
```bash
python twitter_bot.py
```
